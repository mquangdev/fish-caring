# Fish Caring

Web app nhắc lịch chăm sóc bể cá / thủy sinh tại nhà: cho ăn, thay nước, bón phân. Thông báo tới điện thoại qua PWA + Web Push.

- Yêu cầu và thiết kế: [docs/spec.md](docs/spec.md)
- Quy ước làm việc cho AI/dev: [CLAUDE.md](CLAUDE.md)

## Stack

- Backend `be/`: Java 21, Spring Boot 3 (monolith), Maven, MySQL 8
- Frontend `fe/`: React, Vite, TypeScript, Tailwind, Redux Toolkit

## Trạng thái

MVP1 đang phát triển trên nhánh `feature/mvp1`. Hiện mới có tài liệu và cấu trúc thư mục; chưa scaffold code.
